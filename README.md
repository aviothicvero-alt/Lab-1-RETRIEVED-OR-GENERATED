1. Traditional AI vs Generative AI
Traditional AI: Analyses existing data to predict, classify, detect patterns and recommend.
Generative AI: Creates new content such as text, summaries, images, ideas and presentations.
They can work together in aviation:
Operational data → Traditional AI prediction → GenAI communication → Human review → Passenger communication.
Human verification is important because AI-generated information can be incorrect or incomplete.

3. Retrieved vs Generated Information

This is an important concept.

Retrieved information = information obtained from an existing source/system.
Example: Current flight status shown by an airline's operational system.

Generated information = new content created by AI.
Example: AI writing a passenger email about a flight delay.

For aviation information such as:

Flight status
Baggage rules
Regulations
Passenger rights
Safety/security information

you should verify the information using an authoritative/current source before communicating it.

4. Four Main AI Capabilities
Capability	Meaning	Aviation Example
Prediction	Estimates what may happen	Predicting flight delays
Classification	Places information into categories	Categorising complaints
Recommendation	Suggests a suitable option	Suggesting passenger offers
Generation	Creates new content	Writing a passenger announcement

The key lesson is: first identify the business problem, then select the appropriate AI capability.

5. AI Output Types & Tool Selection

Different tasks require different outputs:

Passenger email → Text
Advertisement visual → Image
Training voiceover → Audio
Destination promotional clip → Video
Python function → Code
Flight-delay probability → Prediction
Complaint categorisation → Classification
Presentation outline → Presentation

For current aviation regulations or baggage policies, the file emphasizes search/retrieval + verification rather than relying only on generation.

6. Business-Level Prompting

The file also demonstrates how the same task can be prompted at different levels:

Simple → Advanced → Business

As the prompt becomes more advanced, it adds:

More context
More specific requirements
Formal/professional tone
Action points
Deadlines
Accountability
Business objectives

For example, a simple complaint-update email only asks for the status, action taken and resolution date, while the business-level version also asks for the responsible team, outstanding issues, deadline, accountability and service excellence.

⭐ What you should remember for the exam

Traditional AI = Analyse / Predict / Classify / Recommend

Generative AI = Create

Retrieved = Existing information from a source

Generated = New content created by AI

Prediction = Future outcome

Classification = Category

Recommendation = Suggest an option

Generation = Create content

Important aviation rule:

AI output ≠ automatically verified information.

For important aviation information, retrieve/check the official source → verify → then communicate.

And the overall workflow to remember is:

Business Problem → AI Capability → Appropriate Tool → Output → Human Verification → Business Use.
